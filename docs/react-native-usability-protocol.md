# React Native Usability Protocol (SC-002, SC-004)

## Objectives

- SC-002: >=95% of participants complete top 5 diagnostic tasks unaided.
- SC-004: >=90% of participants report improved navigation clarity.

## Participants

- Minimum 20 Android users across novice/intermediate/advanced cohorts.
- Include at least 5 existing AndrOBD users.

## Task Set

1. Connect to adapter.
2. Retrieve vehicle info.
3. Read fault codes.
4. Switch to live data and change view mode.
5. Load recording and export.

## Metrics

- Task completion success/failure.
- Number of hints requested.
- Time-to-completion per task.
- Post-task 5-point clarity rating.

## Pass Criteria

- SC-002 pass: 19/20 participants complete all 5 tasks without assistance.
- SC-004 pass: average clarity score >=4.5/5 and >=90% improved vs legacy baseline.
